Cleo Pulse Dot

The Cleo tab has a small pulsing gold dot (6px) in the top-right corner. It pulses when Cleo has generated a new insight or suggestion that hasn't been viewed. The dot disappears when the user visits the Cleo tab. This creates a subtle "Cleo is alive" signal without being intrusive.

Implementation

Built with Expo Router's <Tabs> layout in app/(main)/_layout.tsx. Custom tabBar render function for the glass effect. Each tab maps to a folder: (broadcast), (arc), (archive), (cleo). The blur effect uses expo-blur's BlurView. Tab bar hides during Cleo Speaking overlay (opacity 0.3, pointer-events none).

During Cleo Speaking

When the disruption overlay is active, the tab bar dims to 30% opacity and becomes non-interactive. The Cleo tab's pulse dot activates. This prevents navigation during the immersive speaking moment, matching how the player controls also dim.
