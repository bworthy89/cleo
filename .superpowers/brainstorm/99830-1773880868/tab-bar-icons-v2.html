Profile & Settings

Icon Rendering in React Native

Use @expo/vector-icons with MaterialCommunityIcons or install react-native-vector-icons with MaterialSymbols. The filled/outlined toggle is controlled by the fill prop — active tabs use filled variant, inactive use outlined. This matches the Stitch pattern exactly where the active tab icon gets font-variation-settings: 'FILL' 1.

Why These Icons Work

sensors — radio/broadcast waves, matches the "live radio" metaphor. timeline — the session arc is literally a timeline. library_music — collection/archive of past sessions. blur_on — the Cleo orb motif, used throughout the app as her signature visual element (commentary cards, FAB, onboarding).
