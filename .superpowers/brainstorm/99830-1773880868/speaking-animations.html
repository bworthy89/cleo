React Native Implementation

All animations use Reanimated 3 for 60fps native thread performance. The scanline and waveform bars use withRepeat + withTiming. The entrance sequence uses withSequence for orchestrated stagger. Word highlighting is driven by the TTS playback position from CleoVoiceEngine — each word maps to a timestamp range. Respects reduce-motion — falls back to simple fade in/out.
