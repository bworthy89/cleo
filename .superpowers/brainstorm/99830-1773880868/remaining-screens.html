Session Arc (Queue)

Arc Visualization

SVG curved path with gold→vibe gradient. Cleo moment nodes along the arc. "You are here" indicator. Built with react-native-svg. Animates as session progresses.

Current Track Card

Glass card with art, metadata, genre/BPM tags, and live waveform indicator. Tappable — navigates to Broadcast tab.

Session Pulse

Energy level (from SessionEngine scoring) and time remaining. Gold for energy, vibe accent for time. Feeds from existing QueueManager data.

Upcoming Manifest

Track list with Cleo commentary nodes interspersed. Commentary nodes use vibe accent color + EB Garamond title. Matches SegmentController's pre-load buffer.

Data Sources

All data from existing services: QueueManager (tracks), SessionEngine (energy/timing), SegmentController (Cleo moments). No new backend work.

Profile & Settings

Profile Header

Gold gradient ring around avatar (same ring used in Stitch). Name in Playfair. PRO badge if subscribed (future). Pulls from Firebase Auth profile.

AI Personality

3 personality modes that modify Cleo's system prompt (static-core.ts). Curator = analytical, Companion = emotional, Oracle = experimental. Stored in MMKV. Radio-button selection.

Connected Ecosystem

Apple Music toggle. Shows connection status from MusicKitPlayer. Future: Spotify, Last.fm.

Voice Profile

Audio Fidelity = placeholder for future quality toggle. Host Volume Mix = actual CleoVoiceEngine ducking level. The -4dB maps to AudioCoordinator.duck.targetVolume.

Account

Subscription management (StoreKit, future). Sign out calls AuthService.signOut(). Error color for destructive action.
